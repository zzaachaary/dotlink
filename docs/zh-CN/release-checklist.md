## 最新反馈与通知验收

2026-10-20，所有者反馈通知设置成功，但最新设置中的 Charging 无法工作。此反馈与上方按日期保留的充电成功记录分别记录，不表示已测得成功率或已完成独立安装复现。

- [ ] 按[部署指南](deployment.md)完整走一次：部署 → 7 项配置 → dot 连接 → 仅通知订阅 → Notifications 输入绑定 → 选定来源的真实通知。
- [ ] 确认 `iphone-primary` 已启用，以 arguments `{"device_ids":["iphone-primary"],"kinds":["notification"]}` 订阅 `phone.event`，记录实际到期时间及客户端续订限制。
- [ ] 将自动收到的新通知与对应 dot 回执核对，记录来源、时间、实际可见事件 ID、首次／重复及锁屏行为。无通知输入的手动运行或历史查询不能证明自动投递。三条成功回执只是有限样本，不代表成功率保证；需要持续转发时，测试后继续保留订阅。
- [ ] 需要公开可靠性承诺时，再验证跨原租约期限的新事件、恢复网络／重启、权限撤销和持续观察。无手机 outbox 或 cursor replay，不承诺 100% 送达、离线必达、瞬时投递或全部 App。

Charging、Focus On 和 Focus Off 保持即将推出。它们的历史记录保留在上方及验证记录中；当前不提供其安装或启用步骤。

短演示与社交帖子按实际通过范围撰写，由所有者另行发布；它们不是安装成功证据。

## 检查单独维护的文档原稿

执行 `npm run check:release -- --docs-root /path/to/public-documents`，该目录按公开相对路径包含全部 Markdown、LICENSE 和 NOTICE。缺失、非文本或符号链接将失败，不会退回冻结副本；源码仍取自代码目录，此命令不导出文件。

原稿通过不代表未来压缩包已通过。最终导出仓库仍须执行默认发布检查并比对逐文件哈希。不得上传整个笔记库或内部验收记录。
